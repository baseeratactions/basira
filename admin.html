بصيرة للمعاملات ذ.م.م

تحرير صفحات الموقع مباشرة: النصوص والصور والأقسام والروابط، بالإضافة والحذف والتعديل والترتيب، ثم النشر بضغطة واحدة.

كيف أحصل على مفتاح الدخول؟ (مرة واحدة، دقيقتان)
  1. افتح صفحة إنشاء مفتاح جديد في GitHub ↗ وأنت داخل إلى حساب baseeratactions.
  2. في Repository access اختر Only select repositories ثم المستودع basira.
  3. في Permissions ← Repository permissions اجعل Contents على Read and write.
  4. اضغط Generate token، وانسخ المفتاح والصقه هنا.

المفتاح يمنح صلاحية تعديل هذا الموقع فقط، ويُحفظ على جهازك وحده، ولا يُرسل إلا إلى GitHub. يمكنك إلغاؤه في أي وقت من الصفحة نفسها.
